# 🦙 RAG Chat with LLaMA3

A Streamlit-based chatbot that uses Retrieval-Augmented Generation (RAG) to answer questions from uploaded PDF documents.

## 🚀 Features
- Upload PDF documents
- Ask questions in natural language
- Context-aware answers using LLaMA3
- Shows source text for answers

## 🛠️ Tech Stack
- Python
- Streamlit
- LangChain
- Ollama (LLaMA3)
- Qdrant (Vector DB)

## ▶️ How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the app:
   streamlit run streamlitrag.py

3. Make sure Ollama is running:
   ollama pull llama3

## 📌 Project Goal
To explore how LLMs + retrieval can be combined to build intelligent, context-aware applications.
